四根支柱，撑起近三年的真实顶会文献

CVPR、AAAI、ICCV、ACL 四大支柱，近三年共 11 届（2024–2026；ICCV 为奇数年会议，取 2023 与 2025）， 每届精选 12 篇、共 132 篇。标题、作者、摘要、 页码与 PDF 链接全部取自会议官方开放获取系统（CVF Open Access / ACL Anthology）或 OpenAlex 收录的 AAAI 官方记录；英文摘要由本项目逐篇人工译为中文，主题标签为基于官方 标题与摘要的项目内派生分类。每条记录都带来源与抓取时间，可点链接回原站复核。

数据源

CVPR / ICCV：CVF Open Access
ACL：ACL Anthology
AAAI：OpenAlex · Proceedings of AAAI

口径说明

摘要中文＝人工翻译，非机翻；原文一字未改，可在详情内展开对照。
主题标签＝本项目按官方标题/摘要派生，不是出版方学科分类。

复现

python scripts/fetch_corpus.py 拉官方目录 → build_papers.py 补摘要 → build_data.py 注入前端。 设计模式记录见 docs/design-references.md。
